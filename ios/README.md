# WiiUDownloader for iOS

A SwiftUI port of [WiiUDownloader](https://github.com/Xpl0itU/WiiUDownloader). The
upstream desktop app is Go + GTK4; this port rewrites the core logic in pure
Swift (no Go runtime) and replaces the GTK UI with SwiftUI.

## Layout

```
ios/
├── WiiUCore/                 Swift Package with the ported core logic
│   └── Sources/WiiUCore/
│       ├── Support/          Constants, error type, binary cursor
│       ├── Crypto/           AES-CBC, MD5/SHA1/SHA256, PBKDF2, keygen
│       ├── Formats/          TMD, Ticket, Certificate, FST, U8, Content
│       ├── Titles/           Title database, region/category helpers
│       ├── Progress/         ProgressReporter, pause/cancel controller
│       ├── Download/         NUS client, resumable downloads, validation
│       └── Decrypt/          Content decryption & FST/Wii/WiiU extraction
├── WiiUDownloaderApp/        SwiftUI application
│   ├── Sources/              AppState, RootView, Browse/Queue/Tools/Settings
│   └── Info.plist            Generated by XcodeGen
├── scripts/fetch_title_db.sh Regenerate the bundled title database
└── project.yml               XcodeGen project definition
```

The core package depends only on Foundation, CryptoKit and CommonCrypto.

## Building

Requires macOS with Xcode (or the iOS SDK) and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
# Type-check / build the core library standalone (works with Command Line Tools only)
cd WiiUCore && swift build

# Generate and open the iOS app project
cd .. && xcodegen generate && open WiiUDownloader.xcodeproj
```

Then pick an iOS 16+ simulator or device and run the `WiiUDownloader` scheme.

## Notes

- The Nintendo CDN (`ccs.cdn.c.shop.nintendowifi.net`) serves plain HTTP, so the
  app declares `NSAllowsArbitraryLoads` in its Info.plist.
- Downloads use `.part` + `.resume.json` journals identical to upstream, so
  interrupted transfers resume instead of restarting.
- Downloaded titles land in `Documents/WiiUDownloader` by default (folder is
  exposed in the Files app). Decryption uses the console-independent common keys
  already present in the upstream source.
